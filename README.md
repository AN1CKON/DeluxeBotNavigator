# DeluxeBot Navigator

> 🚀 **Quick Start:** `python run.py`

Профессиональный Telegram бот для создания интерактивных навигационных меню с админ-панелью.

## ⚡ Быстрый запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/AN1CKON/DeluxeBotNavigator.git
   cd DeluxeBotNavigator
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r docs/project/requirements.txt
   ```

3. **Настройте бота:**
   ```bash
   cp .env.example .env
   # Отредактируйте .env файл с вашим токеном
   ```

4. **Запустите:**
   ```bash
   python run.py
   ```
