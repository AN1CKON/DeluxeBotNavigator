# Настройка системы отзывов

## Обзор
Система отзывов позволяет пользователям отправлять отзывы через Telegram бота. Отзывы автоматически отправляются на указанный email адрес.

## Настройка

### 1. Настройка переменных окружения
Добавьте следующие переменные в файл `.env`:

```bash
# Email для получения отзывов
REVIEW_EMAIL=your_email@example.com

# Настройки SMTP сервера (для Gmail)
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_app_password
```

### 2. Настройка Gmail (если используете Gmail)
1. Включите двухфакторную аутентификацию в аккаунте Google
2. Создайте пароль приложения:
   - Перейдите в настройки аккаунта Google
   - Безопасность → Вход в аккаунт Google → Пароли приложений
   - Создайте новый пароль приложения для "DeluxeBotNavigator"
   - Используйте этот пароль в `SMTP_PASSWORD`

### 3. Настройка других почтовых сервисов
Для других почтовых сервисов настройте соответствующие параметры SMTP:

- **Yandex.Mail**: `SMTP_SERVER=smtp.yandex.ru`
- **Mail.ru**: `SMTP_SERVER=smtp.mail.ru`
- **Outlook**: `SMTP_SERVER=smtp-mail.outlook.com`

### 4. Создание кнопки отзыва
1. Войдите в админ-панель бота
2. Выберите "Добавить" → "Оставить отзыв"
3. Настройте заголовок кнопки (например, "💬 Оставить отзыв")
4. Добавьте изображение (опционально)
5. Кнопка появится в главном меню

## Использование
1. Пользователь нажимает на кнопку "Оставить отзыв"
2. Открывается форма для написания отзыва
3. После отправки отзыв приходит на указанный email
4. Пользователь получает подтверждение об успешной отправке

## Формат email отзыва
```
Тема: Отзыв от пользователя @username

Новый отзыв от пользователя:

👤 Пользователь: @username
🆔 ID: 123456789
📝 Имя: Иван Иванов

💬 Отзыв:
[Текст отзыва пользователя]

---
Отправлено из Telegram бота DeluxeBotNavigator
```

## Безопасность
- Email настройки хранятся в переменных окружения
- Пароли не хранятся в коде
- Используйте пароли приложений вместо основных паролей
- Включите двухфакторную аутентификацию

## Устранение неполадок
- Проверьте правильность SMTP настроек
- Убедитесь, что порт 587 не заблокирован
- Проверьте, что пароль приложения создан правильно
- Посмотрите логи бота на наличие ошибок отправки email
