## 🔧 Самостоятельное решение проблем

### Частые проблемы и решения

#### Бот не запускается
```bash
# Проверьте Python
python --version

# Проверьте зависимости
pip list | grep aiogram

# Проверьте логи
tail -f logs/deluxebot_$(date +%Y%m%d).log
```

#### Ошибки базы данных
```bash
# Проверьте файл БД
ls -la src/database/data/menu.db

# Восстановите из backup
cp backup/menu_latest.db src/database/data/menu.db
```

#### Проблемы с Telegram API
- Проверьте токен бота
- Проверьте лимиты API
- Проверьте статус Telegram

### Часто задаваемые вопросы (FAQ)

**Q: Как добавить нового администратора?**
A: Добавьте его Telegram ID в переменную ADMIN_ID в файле .env

**Q: Как сделать резервную копию?**
A: Скопируйте папки `src/database/data/` и `src/media/`

**Q: Как обновить бота?**
A: Остановите бота, скачайте новую версию, установите зависимости

В случае критических проблем:
1. Остановите бота: `sudo systemctl stop deluxebot`
2. Создайте backup всех данных
3. Свяжитесь с поддержкой по телефону
4. Предоставьте доступ к серверу (по согласованию)
