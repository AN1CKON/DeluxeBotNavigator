# РУКОВОДСТВО АДМИНИСТРАТОРА
# DeluxeBot Navigator

## 👋 Введение

Это руководство поможет вам настроить и управлять ботом DeluxeBot Navigator для создания интерактивных меню в Telegram.

## 🔐 Доступ к админ-панели

### Первый вход
1. Убедитесь, что ваш Telegram ID указан в файле `.env` (переменная `ADMIN_ID`)
2. Запустите бота
3. Напишите боту `/admin` в Telegram
4. Бот отправит вам клавиатуру администратора

### Проверка прав администратора
- Только пользователи с ID из `ADMIN_ID` имеют доступ к админ-функциям
- Для нескольких администраторов укажите ID через запятую: `ADMIN_ID=123456789,987654321`

## 🎛️ Основные функции админ-панели

### 📝 Управление меню

#### Создание нового меню
1. Выберите "➕ Добавить раздел"
2. Введите название раздела
3. Добавьте пункты меню:
   - Текст
   - Ссылка (опционально)
   - Изображение (опционально)

#### Редактирование меню
1. Выберите "✏️ Редактировать меню"
2. Выберите раздел для редактирования
3. Выберите пункт меню
4. Внесите изменения

#### Удаление элементов
1. Выберите "🗑️ Удалить"
2. Выберите элемент для удаления
3. Подтвердите удаление

### 🎨 Работа с медиа

#### Добавление изображений
1. Выберите пункт меню
2. Выберите "🖼️ Добавить изображение"
3. Отправьте изображение боту
4. Изображение будет сохранено в `src/media/image/`

#### Добавление видео
1. Аналогично изображениям
2. Видео сохраняются в `src/media/video/`

### 👥 Управление пользователями

#### Просмотр статистики
- Общее количество пользователей
- Активность пользователей
- Популярные разделы меню

#### Управление доступом
- Добавление/удаление администраторов
- Настройка прав доступа

## ⚙️ Настройка бота

### Основные настройки
Файл `src/config/config.py` содержит:
- Настройки базы данных
- Параметры логирования
- Настройки Telegram API

### Переменные окружения (.env)
```env
BOT_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
LOG_LEVEL=INFO
DB_PATH=src/database/data/menu.db
```

## 📊 Мониторинг и логи

### Просмотр логов
Логи хранятся в папке `logs/`:
- `deluxebot_YYYYMMDD.log` - основные логи
- Уровни логирования: DEBUG, INFO, WARNING, ERROR

### Мониторинг работы
- Проверяйте логи на ошибки
- Мониторьте использование ресурсов сервера
- Следите за обновлениями Telegram API

## 🔧 Обслуживание

### Резервное копирование
```bash
# Копирование базы данных
cp src/database/data/menu.db backup/menu_$(date +%Y%m%d).db

# Копирование медиа файлов
cp -r src/media backup/media_$(date +%Y%m%d)
```

### Обновление бота
1. Остановите бота
2. Скачайте новую версию
3. Обновите зависимости: `pip install -r docs/project/requirements.txt`
4. Проверьте настройки
5. Запустите бота

### Очистка данных
```bash
# Очистка логов (старше 30 дней)
find logs/ -name "*.log" -mtime +30 -delete

# Очистка временных файлов
rm -rf __pycache__/
rm -rf src/**/*.pyc
```

## 🚨 Устранение неисправностей

### Бот не отвечает на команды
1. Проверьте статус бота: `/status`
2. Проверьте логи на ошибки
3. Перезапустите бота

### Проблемы с базой данных
1. Проверьте права доступа к файлу БД
2. Восстановите из резервной копии
3. Проверьте целостность БД

### Ошибки при отправке медиа
1. Проверьте размер файлов (Telegram ограничивает до 20MB для видео)
2. Проверьте формат файлов
3. Проверьте доступ к папке media
