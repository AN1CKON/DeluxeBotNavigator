# Модульная система управления отзывами

## Обзор
Система управления отзывами теперь разделена на модули для лучшей поддерживаемости и читаемости кода.

## Структура модулей

### 1. `review_spam_protection.py`
**Назначение:** Ядро системы защиты от спама
- Класс `SpamProtection` для управления лимитами
- Проверка возможности оставления отзыва
- Сохранение/загрузка настроек из базы данных
- Запись фактов отправки отзывов

### 2. `review_handler.py`
**Назначение:** Основная логика обработки отзывов
- Обработка формы отзыва (выбор оценки, ввод текста)
- Интеграция с защитой от спама
- Автоматическая очистка сообщений
- Отправка отзывов по email

### 3. `review_admin.py`
**Назначение:** Админ-функционал для управления системой
- Регистрация всех админ-обработчиков
- Управление отзывами (сброс лимитов)
- Переход к настройкам и статистике

### 4. `review_settings.py`
**Назначение:** Управление настройками защиты от спама
- Изменение cooldown между отзывами
- Настройка дневного лимита отзывов
- Сброс настроек к значениям по умолчанию
- Валидация вводимых значений

### 5. `review_stats.py`
**Назначение:** Статистика и аналитика
- Отображение общей статистики отзывов
- Показ настроек защиты
- Навигация по меню управления

### 6. `review_user_management.py`
**Назначение:** Управление пользователями и их лимитами
- Проверка статистики конкретного пользователя
- Сброс лимитов для отдельных пользователей
- Отображение времени до следующего отзыва

## Интеграция с admin_menu.py
Основной файл `admin_menu.py` теперь:
- Импортирует функции регистрации из всех модулей
- Регистрирует все обработчики в функции `register_admin_menu()`
- Не содержит дублированного кода

## Преимущества модульной структуры
1. **Разделение ответственности** - каждый модуль отвечает за свою область
2. **Легкость поддержки** - изменения в одном модуле не затрагивают другие
3. **Переиспользование кода** - функции можно использовать в разных контекстах
4. **Читаемость** - код организован логично и легко найти нужную функциональность

## Использование
Все модули автоматически регистрируются при вызове `register_admin_menu(dp, bot)` в основном приложении.
