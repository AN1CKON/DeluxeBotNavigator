# Модуль базы данных DeluxeBotNavigator

## Структура модуля

Модуль базы данных разделен на логические подмодули для лучшей организации и поддерживаемости кода:

### Основные модули

- **`base.py`** - Базовые функции подключения к БД и инициализации
- **`menu_crud.py`** - CRUD операции с элементами меню
  - `add_menu_item()` - Добавление нового элемента меню
  - `delete_menu_item()` - Удаление элемента меню
  - `update_menu_item()` - Обновление элемента меню
  - `clear_all_menu()` - Очистка всех элементов меню

- **`menu_queries.py`** - Функции для запросов к меню
  - `get_menu_item()` / `get_menu_item_by_id()` - Получение элемента по ID
  - `get_all_menu_items()` - Получение всех элементов
  - `get_child_menu_items()` - Получение дочерних элементов
  - `get_menu_items()` - Получение списка элементов с позициями
  - `get_menu_items_grouped()` - Группировка элементов по позициям

- **`menu_utils.py`** - Утилитарные функции
  - `has_children()` - Проверка наличия дочерних элементов
  - `change_menu_position()` - Изменение позиции элемента
  - `update_menu_item_image()` - Обновление изображения
  - `check_menu_item_exists()` - Проверка существования элемента
  - `get_menu_path()` - Получение пути к элементу
  - `search_menu_items()` - Поиск элементов

- **`menu_stats.py`** - Статистические функции
  - `get_menu_stats()` - Базовая статистика
  - `get_menu_statistics()` - Подробная статистика

- **`admins_crud.py`** - CRUD операции с администраторами
  - `add_admin()` - Добавление администратора
  - `remove_admin()` - Удаление администратора
  - `update_admin_info()` - Обновление информации
  - `clear_all_admins()` - Очистка всех администраторов

- **`admins_queries.py`** - Запросы и проверки администраторов
  - `is_admin()` / `is_super_admin()` - Проверки ролей
  - `get_admin()` / `get_admin_info()` - Получение информации
  - `get_all_admins()` - Все администраторы
  - `get_admins_count()` - Количество администраторов

- **`admins_management.py`** - Управление ролями и инициализация
  - `promote_to_super_admin()` - Повышение до суперадмина
  - `demote_from_super_admin()` - Понижение роли
  - `init_super_admin()` - Инициализация суперадмина

- **`admins_stats.py`** - Статистика по администраторам
  - `get_admins_statistics()` - Полная статистика

- **`users.py`** - Управление пользователями
- **`positioning/`** - Модули для позиционирования элементов

### Обратная совместимость

Все функции доступны через основной модуль `database`, поэтому существующий код продолжит работать без изменений.

### Использование

```python
# Импорт из основного модуля (рекомендуется)
from ...database import add_menu_item, get_menu_item, get_menu_stats

# Или импорт из конкретного подмодуля
from ...database.menu_crud import add_menu_item
from ...database.menu_queries import get_menu_item
from ...database.menu_stats import get_menu_stats

# Импорт функций позиционирования
from ...database import move_button_up, group_buttons, can_move_up_new
```

### Преимущества новой структуры

1. **Модульность** - Легче найти и модифицировать конкретную функциональность
2. **Поддерживаемость** - Меньше конфликтов при работе в команде
3. **Тестируемость** - Легче тестировать отдельные компоненты
4. **Читаемость** - Код организован по логическим группам
5. **Обратная совместимость** - Существующий код не требует изменений
