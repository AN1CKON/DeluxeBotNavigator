# ⚙️ Настройка DeluxeBot Navigator

**Простое руководство по конфигурации бота**

---

## � Быстрая настройка

### 1. Копирование файла конфигурации
```bash
copy .env.example .env  # Windows
# cp .env.example .env    # Linux/Mac
```

### 2. Заполнение переменных
Откройте `.env` файл и укажите:

```env
# Токен бота (получите у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Ваш Telegram ID (узнайте у @userinfobot)
ADMIN_ID=123456789
```

### 3. Запуск
```bash
python run.py
```

---

## 🔑 Получение токена бота

1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Укажите имя бота
4. Укажите username бота (должен заканчиваться на `bot`)
5. **Скопируйте токен** и вставьте в `BOT_TOKEN`

---

## 🆔 Как узнать свой Telegram ID

1. Найдите [@userinfobot](https://t.me/userinfobot)
2. Отправьте `/start`
3. **Скопируйте ID** и вставьте в `ADMIN_ID`

---

## ✅ Проверка конфигурации

При запуске бот покажет статус конфигурации:

```
📋 Токен бота:         8370271790...LAAFOfC9HE ✅
👤 ID Администратора:  391607541 ✅
```

Если увидите ❌ - проверьте правильность данных.

## � Безопасность

### ✅ Что включено в Git:
- `.env.example` - шаблон с примерами
- `.gitignore` - исключает `.env` из репозитория

### ❌ Что НЕ включено в Git:
- `.env` - ваши реальные токены
- Любые файлы с секретными данными

## � Дополнительные настройки

```env
# Режим отладки (true/false)
DEBUG=false

# Уровень логирования (DEBUG/INFO/WARNING/ERROR)
LOG_LEVEL=INFO
```

### Когда использовать DEBUG:
- При разработке и тестировании
- Для подробного логирования
- При поиске ошибок

## ❓ Устранение проблем

### Бот не запускается
```
Проверьте:
✅ Токен бота правильный
✅ ADMIN_ID указан корректно
✅ Файл .env существует
✅ Зависимости установлены
```

### Ошибка токена
```
ValidationError: BOT_TOKEN должен содержать ':'
Решение: Убедитесь, что токен скопирован полностью
```

### Неверный ADMIN_ID
```
ValidationError: ADMIN_ID должен быть числом
Решение: Используйте только цифры из @userinfobot
```
