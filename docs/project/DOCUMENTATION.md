# 📚 DeluxeBotNavigator - Полная документация

> **Детальное руководство разработчика**

Элегантный и мощный Telegram бот для создания интерактивных навигационных меню с админ-панелью.

## ✨ Основные возможности

- 📂 **Иерархические меню** - создание многоуровневых структур навигации  
- 📄 **Различные типы контента** - текст, ссылки, подменю
- ⚙️ **Админ-панель** - удобное управление через интерфейс бота
- 🧹 **Очистка чата** - быстрое удаление сообщений  
- ✏️ **Редактирование** - изменение существующих пунктов
- 🗑️ **Умное удаление** - удаление элементов и целых разделов
- 🔐 **Контроль доступа** - админ-панель доступна только администратору

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install aiogram
```

### 2. Настройка конфигурации
1. Скопируйте шаблон конфигурации:
   ```bash
   copy .env.example .env
   ```
   
2. Отредактируйте `.env` файл:
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_telegram_id
   ```

### 3. Запуск
```bash
python main.py
```

> 💡 **Получение данных:**
> - Токен бота: [@BotFather](https://t.me/BotFather) → /newbot
> - Ваш ID: [@userinfobot](https://t.me/userinfobot)

## 📋 Использование

### Для пользователей
1. `/start` - запуск бота и показ главного меню
2. Используйте кнопки для навигации по меню
3. Администратор увидит кнопку "⚙️ Админ-панель"

### Для администратора  
1. **Добавление** - создание новых пунктов меню различных типов
2. **Редактирование** - изменение существующих пунктов
3. **Удаление** - удаление отдельных пунктов или целых разделов  
4. **Очистка чата** - быстрое удаление сообщений в чате
5. `/admin` - прямой доступ к админ-панели через команду
