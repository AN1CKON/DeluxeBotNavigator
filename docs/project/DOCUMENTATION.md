# 📚 DeluxeBot Navigator - Документация

**Профессиональный Telegram бот для создания интерактивных меню**

---

## 🚀 Быстрый старт

### Установка и запуск
```bash
git clone https://github.com/AN1CKON/DeluxeBotNavigator.git
cd DeluxeBotNavigator
pip install -r docs/project/requirements.txt
cp .env.example .env  # Настройте BOT_TOKEN и ADMIN_ID
python run.py
```

### Использование
- **Пользователи**: `/start` → навигация по меню
- **Администраторы**: `/admin` → панель управления

---


## 📊 API и функции

### Основные функции базы данных
```python
# Работа с меню
get_menu_items(parent_id=None)     # Получить элементы меню
get_menu_item(item_id)             # Получить элемент по ID
add_menu_item(...)                 # Добавить элемент
update_menu_item(...)              # Обновить элемент
delete_menu_item(item_id)          # Удалить элемент

# Работа с администраторами
add_admin(user_id, ...)            # Добавить администратора
remove_admin(user_id)              # Удалить администратора
get_admins()                       # Получить список админов
```

### Клавиатуры
```python
# Основные клавиатуры
admin_keyboard()                   # Главная админ-панель
style_keyboard()                   # Выбор типа контента
cancel_button()                    # Кнопка отмены

# Специализированные
edit_menu_keyboard()               # Меню редактирования
delete_menu_keyboard()             # Меню удаления
```

## 🔄 Рабочие процессы

### Добавление элемента меню
1. Выбор родительского раздела
2. Выбор типа контента (меню/текст/ссылка/вложение)
3. Ввод заголовка
4. Ввод содержимого (зависит от типа)
5. Опционально: добавление изображения

### Редактирование элемента
1. Выбор элемента для редактирования
2. Выбор действия (изменить заголовок/контент/стиль/изображение)
3. Ввод новых данных
4. Сохранение изменений

### Перемещение элементов
1. Вход в режим перемещения
2. Выбор элементов для группировки
3. Перемещение групп вверх/вниз
4. Разгруппировка при необходимости

```bash
pip list | grep aiogram
```

```bash
# Посмотрите последние логи
```
