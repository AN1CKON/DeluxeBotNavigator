# 👥 Управление администраторами

**Как добавлять и управлять несколькими администраторами бота**

---

## 👑 Типы администраторов

### Супер-администратор
- **Автоматически**: назначается из `ADMIN_ID` в `.env`
- **Полные права**: управление ботом и другими админами
- **Неудаляемый**: нельзя удалить через интерфейс

### Обычный администратор
- **Ограниченные права**: управление меню, но не админами
- **Добавляемый**: супер-админ может добавлять/удалять

---

## 🚀 Как добавить администратора

### 1. Вход в панель управления
Отправьте боту `/admin` (только супер-администратор)

### 2. Переход к управлению админами
Нажмите **"👥 Управление админами"**

### 3. Добавление нового админа
- Нажмите **"➕ Добавить админа"**
- Введите **Telegram ID** пользователя
- Подтвердите добавление

### 4. Получение ID пользователя
- Попросите пользователя написать боту `/start`
- ID появится в логах: `Пользователь ID: 123456789`
- Или используйте [@userinfobot](https://t.me/userinfobot)

---

## 📋 Управление администраторами

### Просмотр списка
- **"📋 Список админов"** - все администраторы с деталями
- Показывает: статус, имя, username, ID, дату добавления

### Удаление администратора
- **"➖ Удалить админа"**
- Введите ID для удаления
- Подтвердите удаление

---

## 🔒 Безопасность

### ✅ Защита
- Только супер-админ может управлять другими админами
- Супер-админа нельзя удалить
- Все действия логируются

### ✅ Валидация
- Проверка существования пользователя
- Защита от некорректных ID
- Автоматическая миграция при обновлении

---

## 🗄️ База данных

Автоматически создается таблица `admins`:

```sql
user_id        - ID пользователя Telegram
username       - username пользователя
first_name     - имя пользователя
added_by       - кто добавил (ID супер-админа)
added_at       - дата добавления
is_super_admin - флаг супер-администратора
```

---

## 🔧 API функции

```python
# Проверка администратора
is_admin(user_id)        # Есть ли права админа?
is_super_admin(user_id)  # Супер-админ?

# Управление
add_admin(user_id, ...)     # Добавить админа
remove_admin(user_id)       # Удалить админа
get_all_admins()            # Список всех админов
```

## ❓ Вопросы и ответы

### Как узнать ID пользователя?
1. Попросите пользователя написать боту `/start`
2. Посмотрите логи бота
3. Или используйте @userinfobot

### Можно ли удалить супер-админа?
Нет, супер-администратор не может быть удален через интерфейс.

### Что происходит при обновлении?
- Автоматическая миграция базы данных
- Существующий ADMIN_ID становится супер-админом
- Все функции остаются работоспособными
