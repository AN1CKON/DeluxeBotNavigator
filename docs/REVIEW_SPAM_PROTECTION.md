# Защита от спама в системе отзывов

## Обзор
Система защиты от спама предотвращает злоупотребление функцией отзывов путем введения ограничений на частоту отправки отзывов пользователями.

## Сохранение настроек

### Автоматическое сохранение
- **База данных**: Настройки сохраняются в таблице `review_spam_settings`
- **Перезапуск**: Настройки восстанавливаются после перезапуска бота
- **Изменения**: Все изменения через админ-панель автоматически сохраняются

### Структура таблицы настроек
```sql
CREATE TABLE review_spam_settings (
    id INTEGER PRIMARY KEY CHECK(id = 1),
    cooldown_minutes INTEGER DEFAULT 0,
    max_reviews_per_day INTEGER DEFAULT 3,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## Механизмы защиты

### 1. Cooldown между отзывами (опционально)
- **Продолжительность**: 0-1440 минут (0 = отключено)
- **Сообщение**: "⏰ Подождите X мин. до следующего отзыва"
- **Цель**: Предотвращает спам в короткие промежутки времени
- **По умолчанию**: Отключен (0 минут)

### 2. Дневной лимит отзывов
- **Количество**: 1-50 отзывов в день
- **Сброс**: Автоматический в полночь
- **Сообщение**: "📊 Достигнут дневной лимит отзывов (X)"
- **Цель**: Ограничивает общее количество отзывов за день
- **По умолчанию**: 3 отзыва

### 3. Админ-панель управления
- **Просмотр статистики**: Количество пользователей, отзывы сегодня, достигшие лимита
- **Изменение настроек**: Настройка cooldown и дневного лимита
- **Сброс лимитов**: Ручной сброс всех лимитов (для админов)
- **Проверка пользователя**: Возможность проверить статистику конкретного пользователя

## Настройка параметров

### Через админ-панель:
1. Войти в админ-панель (`/admin`)
2. Нажать "⭐ Отзывы"
3. Нажать "⚙️ Изменить настройки"
4. Выбрать параметр для изменения:
   - **⏰ Изменить cooldown**: Ввести значение 0-1440 минут
   - **📊 Изменить дневной лимит**: Ввести значение 1-50 отзывов
   - **🔄 Сбросить к умолчанию**: Вернуть к значениям по умолчанию

### Значения по умолчанию:
- **Cooldown**: 0 минут (отключен)
- **Дневной лимит**: 3 отзыва

## Логика работы

### При отключенном cooldown (0 минут):
- Проверяется только дневной лимит отзывов
- Пользователь может отправлять отзывы без ожидания
- Ограничение только по количеству в сутки

### При включенном cooldown (> 0 минут):
- Проверяется время с момента последнего отзыва
- Проверяется дневной лимит отзывов
- Пользователь должен ждать указанное время

## Структура базы данных

### Таблица `user_review_limits`
```sql
CREATE TABLE user_review_limits (
    user_id INTEGER PRIMARY KEY,
    last_review_time INTEGER NOT NULL,
    reviews_today INTEGER DEFAULT 0,
    last_reset_date TEXT NOT NULL
);
```

- `user_id`: ID пользователя Telegram
- `last_review_time`: Время последнего отзыва (Unix timestamp)
- `reviews_today`: Количество отзывов за сегодня
- `last_reset_date`: Дата последнего сброса счетчика

## Мониторинг

Система ведет учет всех попыток отправки отзывов и сохраняет статистику для анализа поведения пользователей.
